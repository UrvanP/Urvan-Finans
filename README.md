# Urvan Finance

Простое веб-приложение для учёта семейного бюджета: HTML + CSS + JavaScript на фронтенде, Supabase (Postgres) как база данных. Без React, без сборки — просто открываете `index.html` в браузере.

## 1. Настройка Supabase

1. Зайдите в свой проект на [supabase.com](https://supabase.com).
2. Откройте раздел **SQL Editor**, создайте новый запрос, вставьте туда содержимое файла [`sql/schema.sql`](sql/schema.sql) и нажмите **Run**. Это создаст все таблицы, включит нужные политики доступа и добавит трёх членов семьи (Паша, Настя, Эйтан) с парой примеров категорий.
3. Откройте **Project Settings → API**. Скопируйте:
   - **Project URL**
   - **anon public** ключ (не `service_role`, именно `anon public`!)
4. Откройте файл [`js/config.js`](js/config.js) и впишите туда эти значения вместо заглушек.

## 2. Запуск приложения

Проще всего просто открыть `index.html` двойным кликом в браузере.

Если браузер будет ругаться на загрузку модулей (редко, но бывает с некоторыми настройками), запустите локальный сервер, например через PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .claude/serve.ps1
```

и откройте `http://localhost:8080`.

## 3. Установка на телефон (PWA)

Приложение — это PWA (Progressive Web App): манифест (`manifest.json`) и service worker (`service-worker.js`) позволяют "установить" его на Android как обычное приложение (иконка на рабочем столе, отдельное окно без адресной строки).

**Важно:** установка на телефон работает только если приложение открывается по `https://` адресу, а не как локальный файл. Нужно один раз выложить папку проекта на бесплатный хостинг:
- [Netlify Drop](https://app.netlify.com/drop) — просто перетащить папку проекта на страницу, сразу получите ссылку;
- или GitHub Pages, если удобнее версионировать через git.

После этого на Android откройте ссылку в Chrome → меню → "Добавить на главный экран".

## 4. Копилки и чекапы

Вместо ежедневных операций для копилок (пенсии, керен иштальмут, инвестиции и т.п.) используется тот же принцип, что был в вашем Excel: раз в месяц (или когда удобно) открываете копилку и вписываете текущую сумму — "чекап". Приложение само считает изменение с прошлого раза и хранит историю с комментариями. Обычные операции (доход/расход по категориям) остались только для текущих счетов и общей наличности.

## 5. Важно про безопасность

Приложение пока без логина — доступ к базе открыт для всех, у кого есть URL и anon-ключ (они всё равно видны в коде фронтенда). Это нормально для личного использования на старте, но при желании расшарить приложение публично — сначала нужно добавить авторизацию и переписать политики доступа (RLS) в Supabase.

## Структура проекта

```
index.html
manifest.json            — PWA-манифест (установка на телефон)
service-worker.js        — офлайн-кэш оболочки приложения
icons/                   — иконки приложения
css/style.css            — стили
js/config.js             — ваши ключи Supabase
js/supabaseClient.js     — подключение к Supabase
js/api.js                — запросы к базе данных
js/app.js                — интерфейс и логика
sql/schema.sql               — SQL-скрипт для создания таблиц (для нового проекта)
sql/migration_2_checkpoints.sql — миграция для уже существующей базы
```
